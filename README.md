<div align="center">
  <h1>Semantic Fashion Search System</h1>
  <p>
    <b>Разработка поисковой системы для маркетплейса одежды, которая понимает текстовые запросы на естественном языке (Natural Language Search) и сопоставляет их с изображениями товаров.</b>
  </p>
</div>
<hr>
<div>
  <h3>Суть проекта</h3>
  <p>
    Стандартный поиск по тегам часто ограничен. В данном проекте реализован <b>семантический поиск</b> с использованием нейросети <b>CLIP</b> (Contrastive Language-Image Pre-training) от OpenAI. Модель была дообучена (fine-tuned) на специфичном датасете модной одежды для повышения точности сопоставления.
  </p>
</div>
<div>
  <h3>Технологический стек</h3>
  <ul>
    <li><b>Модель:</b> <code>openai/clip-vit-base-patch32</code></li>
    <li><b>Фреймворки:</b> PyTorch, Transformers (Hugging Face)</li>
    <li><b>Данные:</b> Pandas, PIL, Matplotlib</li>
    <li><b>Обучение:</b> Contrastive Loss, AdamW optimizer</li>
  </ul>
</div>
<div>
  <h3>Основные этапы работы</h3>
  <ol>
    <li><b>Подготовка данных:</b> Исследование и очистка датасета Fashion Product (44k+ товаров).</li>
    <li><b>Дообучение:</b> Дообучение модели в течение 8 эпох с использованием аугментаций.</li>
    <li><b>Анализ:</b> Мониторинг метрики CLIP-score и функции потерь (Loss).</li>
    <li><b>Инференс:</b> Предварительный расчет эмбеддингов для всей базы товаров и реализация функции семантического поиска.</li>
  </ol>
</div>
<div>
  <h3>Результаты</h3>
  <ul>
    <li>В процессе дообучения метрика <b>CLIP-score</b> на валидационной выборке выросла на <b>~8%</b>, достигнув пика на 7-й эпохе.</li>
    <li>Система успешно справляется со сложными запросами, учитывая цвет, материал и тип одежды (например, <i>"purple sneakers"</i>).</li>
